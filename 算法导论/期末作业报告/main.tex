\section{背景}
文本相似度计算是自然语言处理和计算机科学领域的核心问题之一，在信息检索、抄袭检测、生物信息学、拼写检查等众多领域有着广泛应用。最小编辑距离（Levenshtein距离）作为衡量两个字符串差异的基本方法，通过计算将一个字符串转换为另一个所需的最少单字符编辑操作次数（插入、删除、替换），为文本相似性评估提供了量化依据。

在科研工作中，特别是在文献分析、代码比对等领域，高效准确的文本相似度计算方法能够显著提升工作效率。随着学术文献和科研数据的爆炸式增长，如何快速准确地识别相似文本已成为提高科研效率的关键技术。本实验旨在运用本学期学习的动态规划算法，构建一个高效可靠的文本相似度计算系统，解决实际应用中的文本比对问题，同时深入理解动态规划算法的设计思想与应用价值。

\section{题目}
设计并实现一个基于动态规划的文本相似度计算系统。该系统能够：
\begin{enumerate}
	\item 计算任意两个字符串的最小编辑距离
	\item 基于编辑距离计算文本相似度（相似度 = 1 - 编辑距离/最大字符串长度）
	\item 处理各种边界情况和特殊字符（包括多语言文本）
	\item 提供性能优化方案
	\item 通过多样化的测试用例验证算法正确性和鲁棒性
\end{enumerate}

本实验要求使用本学期所学的动态规划算法作为核心解决方案，注重算法的可解释性与可分析性，避免使用机器学习和深度学习等复杂方法，确保算法的确定性和串行特性。

\section{算法设计与分析}
本实验的核心算法采用动态规划策略解决最小编辑距离问题。动态规划在此问题中展现出显著优势，因为它能够将复杂问题分解为重叠子问题，并通过记忆化存储避免重复计算，从而高效求解最优解。

\subsection{动态规划状态定义}
定义二维DP表$dp[i][j]$表示字符串A的前i个字符转换为字符串B的前j个字符所需的最小编辑操作次数。这种状态定义抓住了问题的本质：将全局转换问题分解为处理前缀子串的局部问题。状态转移过程通过逐步构建解决方案，最终得到全局最优解。

\subsection{状态转移方程}
状态转移方程基于字符匹配情况建立，是动态规划算法的核心逻辑：
\begin{itemize}
	\item \textbf{当$A[i-1] == B[j-1]$时}：当前字符相同，无需操作，直接继承前状态：
	\[ dp[i][j] = dp[i-1][j-1] \]
	
	\item \textbf{当字符不同时}：考虑三种编辑操作的最小代价：
	\[ dp[i][j] = \min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1]) + 1 \]
	其中：
	\begin{itemize}
		\item $dp[i-1][j]$ 表示删除操作（删除A的第i个字符）
		\item $dp[i][j-1]$ 表示插入操作（插入B的第j个字符到A）
		\item $dp[i-1][j-1]$ 表示替换操作（将A的第i个字符替换为B的第j个字符）
	\end{itemize}
\end{itemize}

\subsection{边界条件处理}
边界条件处理是动态规划正确性的关键，确保算法在各种极端情况下的鲁棒性：
\begin{itemize}
	\item 当字符串A为空时：$dp[0][j] = j$（需要插入整个字符串B）
	\item 当字符串B为空时：$dp[i][0] = i$（需要删除整个字符串A）
\end{itemize}

\subsection{算法分析}
该动态规划算法具有以下理论特性：
\begin{itemize}
	\item \textbf{最优子结构}：全局最优解包含子问题的最优解，每个状态$dp[i][j]$都基于更小的子问题最优解计算得出，保证了最终解的最优性。
	
	\item \textbf{重叠子问题}：不同状态之间存在大量重复计算，通过DP表存储避免重复求解，显著提高了计算效率。
	
	\item \textbf{无后效性}：当前状态确定后，后续决策不受之前决策路径影响，符合动态规划的基本要求。
	
	\item \textbf{时间复杂度}：$O(mn)$，其中$m$、$n$分别为两字符串长度。算法需要填充整个$m \times n$的DP表，每个状态的计算时间为常数级。
	
	\item \textbf{空间复杂度}：$O(mn)$（标准实现），可优化至$O(\min(m,n))$（空间优化版本）。
\end{itemize}

从实际应用角度分析，该算法具有计算精确、结果可解释性强、易于实现和调试等优势，特别适合科研场景下的文本相似度计算需求。同时，算法的串行特性使其在各种计算环境中都能稳定运行，无需依赖特殊硬件支持。

\begin{lstlisting}[language=C++, caption=最小编辑距离算法实现]
	// 计算两个字符串的最小编辑距离 (Levenshtein距离)
	int levenshtein_distance(const string& str1, const string& str2) {
		int m = str1.length();
		int n = str2.length();
		
		// 创建二维DP表
		vector<vector<int>> dp(m + 1, vector<int>(n + 1, 0));
		
		// 初始化边界条件
		for (int i = 0; i <= m; i++) {
			dp[i][0] = i;  // 删除i个字符
		}
		for (int j = 0; j <= n; j++) {
			dp[0][j] = j;  // 插入j个字符
		}
		
		// 填充DP表
		for (int i = 1; i <= m; i++) {
			for (int j = 1; j <= n; j++) {
				if (str1[i - 1] == str2[j - 1]) {
					// 字符相同，不需要操作
					dp[i][j] = dp[i - 1][j - 1];
				}
				else {
					// 选择插入、删除或替换操作中的最小值
					dp[i][j] = min({ dp[i - 1][j],     // 删除
						dp[i][j - 1],     // 插入
						dp[i - 1][j - 1]  // 替换
					}) + 1;
				}
			}
		}
		
		return dp[m][n];
	}
	
	// 计算文本相似度 (基于编辑距离)
	double text_similarity(const string& str1, const string& str2) {
		int distance = levenshtein_distance(str1, str2);
		int max_len = max(str1.length(), str2.length());
		
		if (max_len == 0) return 1.0;  // 两个空字符串
		
		return 1.0 - static_cast<double>(distance) / max_len;
	}
\end{lstlisting}

\section{优化尝试}
在实现基础算法后，进行了多方面的优化尝试，以提升系统性能和适用范围。

\subsection{空间复杂度优化}
原始实现使用$O(mn)$的二维DP表，对于长字符串消耗大量内存。优化方案采用滚动数组技术：
\begin{itemize}
	\item 利用动态规划问题特性：当前行计算仅依赖前一行数据
	\item 使用两个一维数组（prev和curr）替代完整二维DP表
	\item 通过prev = curr实现行迭代更新
	\item 始终保持较短的字符串长度作为数组大小
\end{itemize}

\begin{lstlisting}[language=C++, caption=尝试空间复杂度上的优化]
	// 优化空间复杂度的版本 (O(min(m,n)))
	int levenshtein_distance_optimized(const string& str1, const string& str2) {
		if (str1.length() < str2.length()) {
			return levenshtein_distance_optimized(str2, str1);
		}
		
		int m = str1.length();
		int n = str2.length();
		
		// 使用两个一维数组替代二维数组
		vector<int> prev(n + 1, 0);
		vector<int> curr(n + 1, 0);
		
		// 初始化第一行
		for (int j = 0; j <= n; j++) {
			prev[j] = j;
		}
		
		for (int i = 1; i <= m; i++) {
			curr[0] = i;  // 每行的第一个元素
			
			for (int j = 1; j <= n; j++) {
				if (str1[i - 1] == str2[j - 1]) {
					curr[j] = prev[j - 1];
				}
				else {
					curr[j] = min({ prev[j],     // 删除
						curr[j - 1], // 插入
						prev[j - 1]  // 替换
					}) + 1;
				}
			}
			
			// 更新数组
			prev = curr;
		}
		
		return prev[n];
	}
\end{lstlisting}

	\section{实验要求}
	假设有三个同学需要对班里的优秀干部 Alice、Bob、Charles、Douglas 进行投票，最后统计各个 班干部获得的票数。这个时候就可以利用 Shamir 秘密共享将各个投票方的投票分享出去并进行隐私 求和计算。 
	
	借鉴实验 3.2，实现三个人对于他们拥有的数据的平均值的计算。
	
	\section{实验原理}
	
	\subsection{秘密共享}
	秘密共享（Secret Sharing）是一类将秘密拆分为多个份额并分发给不同参与方的密码技术。单个份额不应泄露原始秘密，只有满足重构条件的参与方集合才能恢复秘密。其核心目标是避免秘密集中存放带来的单点泄露风险，同时支持后续的安全多方计算。
	
	在本实验中，每个同学持有一个私有数据。为了在不直接公开各自数据的情况下计算平均值，每个同学先把自己的数据拆成多个秘密份额，再把份额分发给其他同学。随后各同学只在份额层面做加法，最终由计数方根据足够数量的份额重构总和，再除以人数得到平均值。
	
	\subsection{Shamir 门限秘密共享}
	Shamir 秘密共享是一种典型的 $(t,n)$ 门限秘密共享方案。其思想是利用多项式插值：次数为 $t-1$ 的多项式由 $t$ 个不同点唯一确定，而少于 $t$ 个点无法确定该多项式的常数项。
	
	设秘密为 $s$，在有限域 $\mathbb{Z}_p$ 上随机选择一个次数为 $t-1$ 的多项式：
	\[
		f(x)=s+a_1x+a_2x^2+\cdots+a_{t-1}x^{t-1}\pmod p
	\]
	其中 $f(0)=s$，随机系数 $a_1,\ldots,a_{t-1}$ 用于隐藏秘密。对不同的非零横坐标 $x_i$ 计算 $f(x_i)$，得到秘密份额 $(x_i,f(x_i))$。重构时使用拉格朗日插值在 $x=0$ 处求值：
	\[
		f(0)=\sum_{i=1}^{t} y_i \prod_{j\ne i}\frac{0-x_j}{x_i-x_j}\pmod p
	\]
	在模素数 $p$ 下，除法通过乘以模逆元实现。参考代码中的 \texttt{quickpower} 使用快速幂计算 $b^{p-2}\bmod p$，从而依据费马小定理得到 $b$ 的模逆。

	\subsection{基于秘密共享的平均值计算}
	本实验采用 $(2,3)$ 门限方案，即共有 3 个参与方，任意 2 个求和份额即可重构结果。因此每个同学构造一次一阶多项式：
	\[
		f_i(x)=s_i+r_ix\pmod p,\quad i=1,2,3
	\]
	其中 $s_i$ 是第 $i$ 个同学的私有数据，$r_i$ 是随机数。第 $i$ 个同学分别计算 $f_i(1),f_i(2),f_i(3)$，并将第 $j$ 个份额发送给 Student $j$。
	
	Student $j$ 收到三个份额后，只计算份额和：
	\[
		d_j=f_1(j)+f_2(j)+f_3(j)\pmod p
	\]
	由于多项式加法满足线性性质，$d_j$ 实际上是总和多项式 $F(x)=f_1(x)+f_2(x)+f_3(x)$ 在 $x=j$ 处的取值，而
	\[
		F(0)=f_1(0)+f_2(0)+f_3(0)=s_1+s_2+s_3
	\]
	因此计数方只需任选两个 $d_j$ 进行插值重构，就能得到三个数据的总和，再除以 3 得到平均值：
	\[
		\bar{s}=\frac{F(0)}{3}
	\]

	\section{实验过程}
	
	\subsection{实验代码说明}
	本次实验保持参考代码内容完全一致，不对 \texttt{ss\_function.py}、\texttt{ss\_student.py}、\texttt{count\_student.py} 和 \texttt{vote\_counter.py} 进行修改。四个文件的作用如下：
	
	\begin{itemize}
		\item \texttt{ss\_function.py}：实现快速幂、随机多项式生成、多项式取值和拉格朗日插值重构；
		\item \texttt{ss\_student.py}：每个同学输入自己的数据，构造一阶多项式并生成三个秘密份额；
		\item \texttt{count\_student.py}：每个同学读取属于自己的三个份额并求和，生成 \texttt{d\_i.txt}；
		\item \texttt{vote\_counter.py}：计数方读取两个求和份额，重构总和并除以 3 得到平均值。
	\end{itemize}
	
	其中 \texttt{vote\_counter.py} 中的关键平均值计算语句为：
	\begin{minted}[linenos,breaklines,fontsize=\small]{python}
d=ss_f.restructure_polynomial([2,3],d_23,2,p)
# 这一步是为了计算平均值
d = d / 3
print(f'得票结果为：{d}')
	\end{minted}
	虽然输出提示文字仍保留为“得票结果”，但此时变量 \texttt{d} 已经由总和除以 3，因此输出值即为三个输入数据的平均值。
	
	\subsection{生成三个同学的秘密份额}
	本实验沿用投票场景中的二值数据，令三个同学对某一候选人的输入分别为：
	\[
		s_1=0,\quad s_2=1,\quad s_3=0
	\]
	因此明文平均值应为 $(0+1+0)/3=0.333333\ldots$。在不公开各自输入的情况下，三个同学分别执行 \texttt{ss\_student.py} 生成秘密份额。

	\subsection{各同学计算份额和}
	接下来三个同学分别执行 \texttt{count\_student.py}。Student $j$ 读取 \texttt{student\_1\_j.txt}、\texttt{student\_2\_j.txt}、\texttt{student\_3\_j.txt}，并计算：
	\[
		d_j=f_1(j)+f_2(j)+f_3(j)\pmod p
	\]
	该过程只在秘密份额上做加法，不需要知道其他同学的原始输入。
	
	\screenshotfigure{sum.png}{三个同学计算秘密份额和}
	
	本机一次运行生成的三个求和份额如下：
	\[
		d_1=736384041,\quad d_2=472768074,\quad d_3=209152107
	\]
	三个求和结果分别写入 \texttt{d\_1.txt}、\texttt{d\_2.txt}、\texttt{d\_3.txt}。
	
	\screenshotfigure{dfiles.png}{生成的求和份额文件}
	
	\subsection{重构总和并计算平均值}
	最后计数方执行 \texttt{vote\_counter.py}。该程序读取 \texttt{d\_2.txt} 和 \texttt{d\_3.txt}，使用两个点 $(2,d_2)$、$(3,d_3)$ 对总和多项式 $F(x)$ 做拉格朗日插值，恢复 $F(0)$。
	
	在本次运行中，总和多项式的一次项系数为：
	\[
		481449096+538118585+716816366\equiv 736384041\pmod {1000000007}
	\]
	所以总和多项式可表示为：
	\[
		F(x)=1+736384041x\pmod {1000000007}
	\]
	对应的 $F(2)=472768074$、$F(3)=209152107$ 与文件中的 \texttt{d\_2.txt}、\texttt{d\_3.txt} 一致。通过插值恢复得到：
	\[
		F(0)=1
	\]
	因此平均值为：
	\[
		\bar{s}=\frac{1}{3}=0.3333333333333333
	\]

	\end{lstlisting}
	结果与明文直接计算的 $(0+1+0)/3$ 一致，说明利用 Shamir 秘密共享可以在不公开各同学原始数据的前提下完成平均值计算。


	\section{结论与实践心得}
	通过实验可以看到，Shamir 秘密共享不仅可以恢复单个秘密，也可以利用其线性性质完成隐私求和。每个参与方只暴露多项式取值形式的份额，计数方只获取两个求和后的份额，因此不会直接得到某个同学的原始输入。在本实验采用的 $(2,3)$ 门限设置下，任意两个求和份额即可重构总和，少于两个份额则无法确定总和多项式。
	
	本实验也体现了秘密共享方案的局限：参与方数量和门限值需要提前确定；协议要求各参与方正确保存和传递份额；如果扩展到更复杂的数据类型或更大规模参与方，还需要考虑通信开销、恶意参与方校验和可验证秘密共享等问题。总体来看，Shamir 秘密共享结构清晰、实现成本较低，是理解安全多方计算中隐私求和与平均值计算的重要基础。
